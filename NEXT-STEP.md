# Next-step assistance arrow

A presentation-only, local rule-based guide suggests a relevant next click as soon as the game is ready. It does not use a remote AI service. A 52px filled arrow, short explanation and non-interactive target outline show the recommended button without selecting or activating it.

Each cue lasts 4.8 seconds: a brief fade-in, six 650ms directional nudges, then a fade-out; the arrow and outline are hidden together when the one-shot timer expires. Rerenders, scrolling and resize reposition an active cue without restarting or extending it. The same expired step stays hidden; a different recommendation or completed-action state creates a new cue. Closing and reopening Smart Guide replays the current recommendation. Turning it off, blocking the guide, leaving the page, starting a new game or returning to the menu clears the old timer. At most one cue timer exists.

During investigation, prioritize ready enemies engaged at the current location (suggest trying evade when health/sanity is near the combined attack damage, otherwise fight; use only enabled buttons). Then suggest advancing the act with at least 3 clues, moving towards the attic after the act advances, or completing investigation there. Otherwise suggest investigating a location with clues, moving towards the nearest unexplored or revealed clue-bearing location, or drawing/gaining a resource as a fallback. Full hands are not encouraged to draw more. These are basic suggestions, not guaranteed-success or optimal-play claims. Hidden location names and clue amounts are not disclosed.

Movement selection points at one actual adjacent button using a presentation-only data attribute; the player may choose any destination or return. Continue in confirmations includes the Back reminder. Tests still allow optional skill commits and guide draw/resolve; exhausted actions point to End Turn and other phases to Continue. The guide never ends a turn while actions remain, auto-plays cards, draws random tokens, executes moves or modifies game state.

The arrow and outline hide during phase countdowns, onboarding/inert game state, native inspection dialogs, unavailable targets, game over and the start menu. A default-on Smart Guide toggle is always available in the game header, outside the collapsible play guide. It changes only assistance for the current page session. Native button keyboard behavior and the existing three-column layout remain unchanged.

Position is computed from the current button's bounding rectangle, which also accounts for the one-screen board's scale. Scroll, resize, visual-viewport changes and UI mutations schedule at most one animation-frame update. Positions clamp within the viewport; the arrow tip offsets within its tooltip to stay pointed at the button even near the left/right edge. For offscreen controls it indicates the appropriate scroll direction without changing scroll/focus. Observers watch the game/modal/tutorial/native dialogs, not the arrow or outline, avoiding self-triggered loops. No polling, auto-clicks or gameplay mutations. The only added timer is the bounded cue expiry.

Styles reuse the local SVG icon sheet and noir palette, with a simple filled guide-pointer symbol. The cue uses only opacity and transform animations, with finite repeat counts rather than a perpetual blink. The existing Smart Guide switch stops the animation and hides the cue. prefers-reduced-motion disables all cue animation while retaining the 4.8-second large static pointer. All overlays remain pointer-events:none and aria-live polite, without occupying layout or intercepting touches. No dependencies added.

Verification: 27 guide tests cover target selection, new-game hints, clue progression, path selection, dangerous enemies, fallback supplies, modal/phase locks, disabled/missing/replaced targets, viewport position, all offscreen directions, toggle, state/focus preservation, observer scheduling, finite cue expiry, replay suppression, timer cleanup and reduced-motion styles. The complete regression suite includes gameplay, layout, cards, tutorial, phases and audio. Browser visual verification was not performed.
