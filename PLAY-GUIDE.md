# Contextual play guidance

A compact, initially open native details panel below the phase bar explains the current situation. Users can collapse it; rendering updates only its text and preserves the chosen open/closed state. The same guidance function supplies the existing three-second phase popup, so explanations remain available after the popup disappears.

The first-round explanation correctly says Mythos is skipped at opening; Enemy still occurs. With no enemies, the Enemy message explains that no attack takes place, not that the phase was removed. Later guidance covers opportunity attacks from ready engaged enemies, action exhaustion, enough clues to advance the simplified act, travel to the attic, completion, upkeep benefits, Mythos/encounter cards, optional versus forced tests, resolved tokens and endings. No rules, phase ordering, randomness, costs or state mutations are introduced.

Source: FFG original Learn to Play (2016), printed p.9, Round Sequence: https://images-cdn.fantasyflightgames.com/filer_public/88/53/88538d11-5274-4b4a-ac8c-e8d758f71132/ahc01_learn_to_play_web.pdf#page=9 . The panel links the source and labels action advice as applying to this simplified web game rather than the complete official scenario.

Verification: 176 automated checks across ten test files, including 7 new guidance tests. Existing countdown tests load the guidance alongside the phase script. Browser visual verification remains unauthorized and was not performed.
