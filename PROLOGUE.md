# Story prologue before the game

The menu Start Game entry opens a three-scene native story dialog before any game state is created. Original Chinese fiction establishes Arkham in 1926, Roland's study, unsettling sounds and the reason to investigate the house. It explicitly labels itself a web adaptation, not official scenario text. Local study/room backgrounds now support three lightweight animated shots: rain at night, warm lamplight with a passing doorway shadow, and mist in the corridor. A slow camera and short text fade accompany each scene. The complete text is always available; there is no typewriter delay or automatic page advancement. Previous/Continue, Begin Investigation, Skip and Return to Menu remain manual.

Animation uses only CSS transform/opacity, runs once per scene (up to 12 seconds), then holds its final frame. Pause/Play persists between scenes; a fresh opening starts normally. Hidden documents and closed dialogs pause presentation. Reduced-motion preferences disable all animation and update live; touch devices disable camera movement. Decorative layers are aria-hidden, pointer-transparent and clipped inside the dialog. The text has a polite live region. No new dependencies, generated media, downloads, noise or audio changes were added.

Reading/backtracking/cancelling does not shuffle, deal cards, spend actions or start phase effects. Difficulty is captured when opening and preserved for the actual game. Final confirmation or Skip calls startGame once, then emits arkham:game-started. The existing three-second first-phase announcement runs next, followed by optional onboarding. The Learn entry passes a forced tutorial request through the prologue. Start-button audio behavior remains; the actual-start event also supports the Learn path. Cancelling dispatches the existing menu event to stop ambience/clear tutorial queues.

Native modality provides keyboard containment; scene titles receive focus and Escape returns to the menu. Return restores focus and body overflow. The background is local, the dialog is viewport-height bounded and scrollable, and short-landscape/narrow layouts retain 44px controls. Ongoing games cannot reopen the prologue; fresh games replay it. Missing presentation script falls back to the original game start.

Verification: 217 automated tests across twelve files, including twelve prologue flow/presentation tests covering all scenes, pause/resume, visibility, reduced motion, manual navigation and safe game startup. Browser visual verification remains unauthorized and was not performed.
