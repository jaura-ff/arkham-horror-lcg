# Simplified noir home screen

The start screen prioritizes title, one-line atmosphere, Start Game and the current difficulty. Former long story paragraphs, route spoilers and three numerical summaries are removed from the initial view. A noninteractive decorative case seal retains the noir composition without adding controls; hidden on narrow portrait screens.

Four fixed tiles form a two-by-two grid: Difficulty Settings, Game Settings, Beginner Tutorial and Card Atlas. Each opens a native modal instead of expanding the landing page. Difficulty contains the original selector, chaos-bag details and official source; Game Settings contains synchronized sound controls; Tutorial starts only after explicit confirmation; Atlas retains search/filter and adds a Confirm close button. Original IDs/listeners remain unique. Ordinary Start still enters the prologue without forcing onboarding.

Menu sound controls proxy the original controls, preserving one saved preference and audio context. Changing settings before entry cannot autoplay audio. Existing game/prologue controls and menu mirrors synchronize, including unsupported browsers. Prologue narration retains its independent switch. No audio/media assets or gameplay rules changed.

home-dialogs.js guards against duplicate home dialogs, restores focus and overflow on Confirm, Escape or native close, and synchronously cleans up before Tutorial opens the prologue. Delayed close events cannot overwrite a newer prologue scroll lock. Native modality, visible focus, 44px controls, viewport scrolling and short-landscape/safe-area rules remain. Homepage content no longer moves when a tile is clicked. Decorative artwork uses the existing local background. Automated regressions cover mappings, IDs, close/cancel and lifecycle guards. Browser visual verification remains unauthorized and was not performed.
