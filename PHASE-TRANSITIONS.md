# Three-second phase announcements

Opening a game announces Investigation. Every later transition announces Enemy, Upkeep, Mythos or Investigation in the existing engine order, with its upcoming round number. A centered native modal reads “即将进入 … 阶段”, displays a large 3 → 2 → 1 countdown at 0/1000/2000ms, and closes automatically after 3000ms without displaying zero. Phase effects execute only after closure. No new automatic phase advancement is introduced: existing Back / Continue confirmations remain. Countdown updates use a polite live region, reset to 3 for each announcement, and are cancelled/identity-guarded together with the close timer.

The phase lock disables actions, cards, navigation and repeated phase requests during the wait. Escape cannot bypass it. A native keyboard/touch-accessible “立即进入” button dismisses only the announcement and immediately executes the pending phase effects; it does not skip the phase. The button and automatic timer share one identity-guarded completion path, cancel all timers and invalidate old callbacks before executing effects. Repeated clicks cannot repeat attacks, supplies, encounters or phase-ready events. Resetting a game cancels the timer, invalidates its callback and closes the prior announcement. Callbacks also verify game identity, phase and defeat state. They execute once; they do not redraw encounters, restore snapshots or close result/test modals created by the phase.

The initial tutorial queues behind the announcement; a phase-ready event opens it only when requested. Only the explicit Learn entry requests onboarding; normal Start Game never opens it. After the announcement, focus moves to the next available game action unless the tutorial or another game modal needs it.

Styles reuse the noir palette, remain static (no motion), fit short landscape viewports and use the native modal top layer, so the page layout does not expand. No media, libraries or dependencies added. If the optional presentation script fails to load, the original synchronous engine still runs.

Verification: 158 automated Node checks across eight test files, including 12 phase/countdown tests with a deterministic fake clock and 2 tutorial-queue tests. Tests check second boundaries, resets, obsolete countdown callbacks, the 2999/3000ms boundary, all phases, phase effects, locks, forced tests and defeat. Browser visual verification remains unauthorized and was not performed.
