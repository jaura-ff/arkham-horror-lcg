# 诡镇奇谭卡牌版 · 单场景网页游戏

下载仓库并用浏览器打开 `index.html` 即可游玩，无需安装依赖。

## 回归验证

使用 Node.js 18 或更新版本，在仓库目录执行：

```sh
node --test tests/game-regressions.cjs
```

测试读取实际 `index.html` 中的游戏脚本，用最小 DOM 替身验证行动、检定、敌人、遭遇、阶段和终局逻辑；不依赖外部测试库。浏览器布局和实际点击体验需另行验证。

## 2026-10-14 修复

- 修复“继续”按钮不能离开敌人阶段，检定尚未结束时阻止提前推进。
- 统一行动限制和扣除时机，打出资产与事件消耗行动，地图移动不能越过行动上限。
- 移动确认时才结算借机攻击；取消不扣行动、不受伤；所有就绪交缠敌人各自攻击。
- 武器修正传入检定；侧身闪避作为事件打出后加成应用于下一次闪避，作为投入牌则只用于当前检定。
- 敌人就绪或调查员进入同地点时自动交缠，猎手一次移动一个相邻地点，力竭猎手不移动。
- 起手弱点放回牌堆，补齐五张正常手牌；遭遇诡计和被击败的普通敌人正确回收。
- 议程推进后仍抽取本轮遭遇；失败后立即停止行动与阶段结算，保留失败提示和重新开始入口。

本次沿用原项目的单场景简化规则，例如武器被动叠加、上古印记自动成功并治疗、有胜利点敌人提供“胜利线索”；不代表完整官方规则模拟。
