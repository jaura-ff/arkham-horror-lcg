Former long story paragraphs, route spoilers and three numerical summaries are removed from the initial view. A noninteractive decorative case seal retains the noir composition without adding controls; hidden on narrow portrait screens.

Two native details groups default closed: Game Settings contains the existing difficulty selector, chaos-bag explanation/source and synchronized master sound/ambience/volume controls; Play Guide contains the original Learn and Card Atlas entries with concise instructions. Shared details name requests exclusive expansion in supporting browsers; older browsers still have working independently collapsible sections. No custom focus trap or extra script is required. Original unique IDs/listeners and dialogs are retained, including difficulty-change bag preview and atlas close focus. Ordinary Start still enters the prologue without forcing onboarding.

Menu sound controls proxy the original controls, preserving one saved preference and audio context. Changing settings before entry cannot autoplay audio. Existing game/prologue controls and menu mirrors synchronize, including unsupported browsers. Prologue narration retains its independent switch. No audio/media assets or gameplay rules changed.

All new styles are scoped to the home screen in home.css. Native keyboard summaries, visible focus, 44px controls, viewport scrolling and short-landscape/safe-area rules remain. Decorative artwork uses the existing local background. Automated source/control regressions cover grouping, IDs, entry paths and preference synchronization. Browser visual verification remains unauthorized and was not performed.
